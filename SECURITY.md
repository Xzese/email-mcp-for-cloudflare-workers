# Security Policy

## Supported version

Security fixes are applied to the latest version on the default branch.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this repository. Do not open a
public issue for a suspected vulnerability and do not include credentials, email content, or
personal data in a report.

Include the affected route or tool, the security impact, reproduction steps, and any suggested
mitigation. You should receive an acknowledgement through GitHub within seven days.

## Deployment responsibility

This repository contains source code, not a hosted public email service. Each operator is
responsible for their own Cloudflare Access policy, Microsoft Entra registration, Worker secrets,
KV namespace, authorized users, monitoring, and credential rotation.
